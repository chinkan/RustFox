# Web UI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a lightweight browser-based chat interface to RustFox that streams LLM responses token-by-token using Server-Sent Events, with no WASM and minimal JS (~21 KB total from CDN).

**Architecture:** Axum 0.8 web server spawned alongside the Telegram bot in `main.rs`. Askama compiles HTML templates at build time (zero runtime overhead). HTMX handles server communication; Alpine.js handles local client state. Each chat request gets a UUID session; the SSE endpoint for that session streams the response as it arrives via a tokio broadcast channel added to `Agent`.

**Tech Stack:** `axum 0.8` (already present), `askama 0.12`, `tower-http 0.6`, `tokio-stream 0.1`, HTMX 2.x (CDN), Alpine.js 3.x (CDN)

```rust
use askama::Template;
use axum::{
    extract::{Path, State},
    http::StatusCode,
    response::{Html, IntoResponse, Sse},
    Json,
};
use serde::{Deserialize, Serialize};
use std::sync::Arc;
use tokio_stream::wrappers::BroadcastStream;
use tokio_stream::StreamExt;

use crate::web::WebState;

// ── Template ───────────────────────────────────────────────────────────────────

#[derive(Template)]
#[template(path = "chat.html")]
struct ChatTemplate;

pub async fn page() -> impl IntoResponse {
    Html(ChatTemplate.render().expect("template render"))
}

// ── Send ───────────────────────────────────────────────────────────────────────

#[derive(Deserialize)]
pub struct SendRequest {
    pub text: String,
}

#[derive(Serialize)]
pub struct SendResponse {
    pub session_id: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<String>,
}

pub async fn send(
    State(state): State<Arc<WebState>>,
    Json(body): Json<SendRequest>,
) -> impl IntoResponse {
    let text = body.text.trim().to_string();
    if text.is_empty() {
        return Json(SendResponse {
            session_id: String::new(),
            error: Some("empty message".into()),
        });
    }

    let session_id = uuid::Uuid::new_v4().to_string();
    let sid = session_id.clone();
    let agent = Arc::clone(&state.agent);

    tokio::spawn(async move {
        let incoming = crate::platform::IncomingMessage {
            platform: "web".into(),
            user_id: "web".into(),
            chat_id: "web".into(),
            user_name: "Web User".into(),
            text,
        };

        match agent.process_message(&incoming).await {
            Ok(response) => {
                // Stream the response in small chunks to simulate token streaming.
                // Replace with real LLM streaming in a future task.
                for chunk in chunk_string(&response, 4) {
                    let _ = agent.web_tx.send((sid.clone(), chunk));
                    tokio::time::sleep(tokio::time::Duration::from_millis(8)).await;
                }
                let _ = agent.web_tx.send((sid.clone(), "\x00DONE".into()));
            }
            Err(e) => {
                let _ = agent.web_tx.send((sid.clone(), format!("\x00ERR:{e}")));
            }
        }
    });

    Json(SendResponse {
        session_id,
        error: None,
    })
}

// ── SSE stream ─────────────────────────────────────────────────────────────────

pub async fn stream(
    Path(session_id): Path<String>,
    State(state): State<Arc<WebState>>,
) -> impl IntoResponse {
    use axum::response::sse::Event;

    let rx = state.agent.web_tx.subscribe();
    let sid = session_id.clone();

    let event_stream = BroadcastStream::new(rx)
        .filter_map(move |result| {
            let sid = sid.clone();
            match result {
                Ok((id, token)) if id == sid => {
                    if token == "\x00DONE" {
                        Some(Ok(Event::default().event("done").data("")))
                    } else if let Some(msg) = token.strip_prefix("\x00ERR:") {
                        Some(Ok(Event::default().event("error").data(msg.to_string())))
                    } else {
                        Some(Ok(Event::default().event("token").data(token)))
                    }
                }
                _ => None,
            }
        })
        .take_while(|e| {
            // Stop streaming after done or error event
            !matches!(e, Ok(ref ev) if {
                let dbg = format!("{ev:?}");
                dbg.contains("\"done\"") || dbg.contains("\"error\"")
            })
        });

    Sse::new(event_stream)
        .keep_alive(axum::response::sse::KeepAlive::default())
}

// ── Helpers ────────────────────────────────────────────────────────────────────

fn chunk_string(s: &str, chars: usize) -> Vec<String> {
    s.chars()
        .collect::<Vec<_>>()
        .chunks(chars)
        .map(|c| c.iter().collect())
        .collect()
}
```

## Task 6: Fix SSE take_while — sentinel-inclusive stream termination

The `take_while` in `chat.rs` currently terminates *before* the done/error event reaches the client. We need `scan` instead to include the terminal event.

**Files:**
- Modify: `src/web/chat.rs`

**Step 1: Replace `take_while` with `scan` in the `stream` handler**

Replace the `event_stream` construction in `src/web/chat.rs::stream`:

```rust
let event_stream = BroadcastStream::new(rx)
    .filter_map(move |result| {
        let sid = sid.clone();
        match result {
            Ok((id, token)) if id == sid => {
                if token == "\x00DONE" {
                    Some(Ok::<_, std::convert::Infallible>(
                        (true, Event::default().event("done").data("")),
                    ))
                } else if let Some(msg) = token.strip_prefix("\x00ERR:") {
                    Some(Ok((true, Event::default().event("error").data(msg.to_string()))))
                } else {
                    Some(Ok((false, Event::default().event("token").data(token))))
                }
            }
            _ => None,
        }
    })
    .scan(false, |done, item| {
        if *done {
            return std::future::ready(None);
        }
        match item {
            Ok((is_terminal, event)) => {
                if is_terminal {
                    *done = true;
                }
                std::future::ready(Some(Ok(event)))
            }
            Err(e) => std::future::ready(Some(Err(e))),
        }
    });
```
